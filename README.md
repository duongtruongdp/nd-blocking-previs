# ND Blocking & Previs

ND Blocking & Previs is a browser-based cinematography blocking and previsualization workspace built with React, TypeScript, Three.js, and Vite.

Milestone 1 establishes the dark filmmaking workspace and an empty Blocking View Stage. Actor blocking, production cameras, timeline editing, project file controls, and preview export are intentionally reserved for later milestones.

## Development

```bash
npm install
npm run dev
```

Validation commands:

```bash
npm run build
npm run lint
npm test
```

Architecture and domain contracts live in [`docs/`](docs/), beginning with [`IMPLEMENTATION_PLAN.md`](docs/IMPLEMENTATION_PLAN.md).
