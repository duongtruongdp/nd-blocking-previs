# Security

Please do not publish sensitive vulnerability details in a public Issue.
Send a private report to
[ndtruong.contact@gmail.com](mailto:ndtruong.contact@gmail.com) with:

- a short description of the issue;
- affected version and platform;
- reproducible steps or a minimal proof of concept; and
- the impact you observed.

Please do not include private production project files, credentials, or other
secrets unless they are essential to the report and have been reviewed for
sharing.
