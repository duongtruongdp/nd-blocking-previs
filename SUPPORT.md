# Support

ND Blocking & Previs is Beta software. The fastest support path is a clear,
reproducible GitHub Issue:

[Open a GitHub Issue](https://github.com/duongtruongdp/nd-blocking-previs/issues)

For private or direct questions, contact
[ndtruong.contact@gmail.com](mailto:ndtruong.contact@gmail.com).

## Include this information

- App version and whether you used the Web App or desktop Beta
- macOS version, browser name/version, or Windows details when relevant
- The shot or operation you were working on
- Exact steps to reproduce the problem
- What you expected and what happened
- A screenshot or short screen recording when it clarifies the issue

Please remove private production material from screenshots and recordings.
Do not attach project files containing confidential work unless you have
explicitly chosen to share them.

For security-sensitive reports, use the private process in
[SECURITY.md](SECURITY.md) rather than a public Issue.
