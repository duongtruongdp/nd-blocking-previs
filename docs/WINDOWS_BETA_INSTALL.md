# Installing ND Blocking & Previs on Windows

## Validation status

**Windows packaging is awaiting final validation.** There is no Windows Beta
download yet, and this guide does not claim that the Windows desktop runtime
has been accepted.

## Planned installation flow

When a validated package is available:

1. Download `ND-Blocking-Previs-Windows.zip` from the published release.
2. Extract the ZIP.
3. Open the installer or application included in that package. The exact
   filename will be documented after Windows packaging is confirmed.
4. Follow the installer prompts, if an installer is provided.
5. Launch ND Blocking & Previs.

Windows security behavior, including SmartScreen prompts, will be documented
after the Windows Beta build is validated. Do not treat this page as a current
Windows download or as authoritative SmartScreen bypass instructions.

For now, use the [Web App](https://blocking.duongtruongdp.net/) or the
[macOS Beta guide](MACOS_BETA_INSTALL.md).
