# ND Blocking & Previs v0.2.0

## Project Workflow & Export Update

ND Blocking & Previs v0.2.0 is a Beta release focused on a more complete
project workflow, stronger desktop recovery, and reliable previs export.

### Highlights

- Multi-Scene project workflow with scene switching and scene-level blocking.
- Camera blocking, Camera Preview, Camera View, capture modes, delivery frames,
  and frame guides.
- Scene and Master Timelines with playback, keyframes, camera moves, and
  workspace refinements.
- Shot Planning and Shot List workflows, including thumbnails and metadata.
- Browser video export and native macOS H.264 MP4 export.
- Optional Shot Information burn-in for exported video.
- Shot List export to PDF, CSV, and XLSX.
- Missing Media Manager for identifying and relinking unavailable media.
- Portable Project Package (`.ndpack`) support for projects that include media.
- Project Camera Defaults for consistent camera setup across scenes.
- Safer Project Save and Quit handling with desktop recovery support.
- Refined workspace density, timeline presentation, Camera Preview, and UI
  controls.

### File formats

- `.ndblock` is the normal project format for saving and reopening project
  documents.
- `.ndpack` is the portable project format. It packages the project together
  with referenced media for transfer to another supported installation.

### Live Review and Collaborative Editing

Live Review and Collaborative Editing are available as Beta workflow
foundations for evaluation and review. They are not represented as a
production-grade collaboration service and should be validated for the
specific network, relay, and project workflow before use on a production.

### Platform support

- Web App: supported through the current hosted deployment.
- macOS: Apple Silicon / arm64 desktop build is supported and distributed
  outside the Mac App Store.
- Windows: no release binary is included in this release; Windows packaging
  remains pending a verified Windows build.

### Known limitations

- The macOS application is distributed outside the Mac App Store and may be
  unsigned or require the system's first-launch security confirmation.
- Windows support is not a published release target yet.
- Export performance and browser graphics behavior remain dependent on the
  host system and available GPU resources.
